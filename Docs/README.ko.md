## 바로 플레이
1. Unity에서 위 씬을 열고 Play.
2. SINGLE PLAYER → AI 3 / 5 / 7명, EASY / NORMAL / HARD → START.
3. 기본은 사람 1명 + AI 5명, NORMAL입니다.
4. 첫 실행 시 짧은 튜토리얼이 표시됩니다. LET'S RIDE를 누르면 시작합니다.

멀티플레이: Steam에 로그인한 뒤 MULTIPLAYER에서 친구용 또는 공개 방을 만듭니다. 방에 들어가면 엘리베이터 안에서 이동하며 대기합니다. 참가자는 R키로 준비/취소하고, 다른 참가자가 모두 준비되면 방장이 R키를 눌러 시작합니다. ESC → INVITE FRIENDS로 Steam 초대 화면을 엽니다. 최대 8명입니다.
현재 개발용 App ID는 480입니다. Steam 연결과 방장 이전 안내는 [STEAM.ko.md](STEAM.ko.md)를 참고하세요.
LAN / DIRECT IP 메뉴에는 기존 UDP 7777 연결도 남아 있습니다. LAN 외부 직접 IP 연결은 별도의 포트 전달이나 VPN이 필요합니다. 자동 방장 이전은 Steam 방에 적용됩니다.

- 카트는 5대가 시간차 진입. 엘리베이터 안쪽까지 들어온 뒤 문 중앙 방향으로 되튀며 승객을 밀고 밖으로 이탈
- 새로운 '늦은 투숙객' 돌진 이벤트
- 도착음, 문 미끄러짐/닫힘, 잡기/해제, 발걸음, 점프, 넘어짐, 충돌, 경고, 던지기, 동물, 승리/탈락, 이동/바람 환경음

## 싱글 구조
GameSession이 SinglePlayer/Multiplayer와 AI 수·난이도를 관리합니다.
싱글은 NetworkManager.StartHost/StartClient를 호출하지 않습니다. 로컬 값과 로컬 시계를 쓰고 네트워크 Transform을 끕니다.
멀티플레이에서는 같은 SessionValue 인터페이스가 NetworkVariable을 사용합니다.
RoundManager, FloorEventManager, PlayerController의 물리 모터, 잡기 및 탈락은 양 모드에서 공유합니다.
별도의 싱글 전용 이벤트 복제본은 없습니다.

AIPlayerController는 5 Hz 센서와 난이도별 반응 지연으로 가상 입력을 만들어 같은 SetMoveInput에 전달합니다.
바람/진공 반대 방향 이동, 빠른 물체 예측 회피, 벽/친구 잡기, 매달림 복귀, 기절 회복과 랜덤 이동을 수행합니다.
AI마다 성격과 실수 확률이 다릅니다. 인간과 AI 모두 실제 충돌·잡기·탈락에 참여합니다.
인간이 탈락해도 AI끼리 진행하며, 결과에는 승자·도달 층·생존 시간을 표시합니다.

## 2026-09-29 난이도 / 무기 / 파손

- 플레이 씬은 `Assets/Elevator/Scenes/Elevator.unity`입니다. Unity에서 기본 `SampleScene`이 열려 있으면 Project 창에서 이 씬을 열어 게임을 확인하세요.
